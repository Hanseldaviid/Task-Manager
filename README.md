# CLI Task Manager (Python)

A Command-Line Interface (CLI) application built with Python to manage tasks, track completion statuses, and filter by priority level.

## 🚀 Features

- **Task Creation:** Register new tasks with title and priority level (`high`, `medium`, `low`).
- **Status Tracking:** Display task list with dynamic completion indicators (`[ X ]` or `[   ]`).
- **Complete Task:** Search task by title and mark it as finished (`complete: True`).
- **Priority Filtering:** Filter and display tasks by specific priority tiers.
- **Robust Input Handling:** Safe execution with bounded `try...except` input loops.

## 🛠️ Built With

- **Python 3.10+**
